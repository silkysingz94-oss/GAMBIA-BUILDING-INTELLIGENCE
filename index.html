10 | METHODOLOGY

Building counts represent valid building polygon features in the loaded dataset.

Footprint area is calculated using Turf.js geodesic polygon area.

Building density is calculated as building count divided by selected administrative area.

The reporting year is not a verified building construction year.

The original Open Buildings script assigns the same collection to every selected year. It does not contain historical annual building observations.

Building footprints do not directly indicate occupancy, household count, number of floors or building use.
